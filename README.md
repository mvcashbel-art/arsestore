# ARSE STORE

Sales, utang, stock and store-map tracker for ARSE STORE (hardware). Works offline as a phone app (PWA).

- Files: `index.html`, `manifest.json`, `sw.js`, and the icons.
- All data stays on the phone. Use Settings → Backup regularly.
- After you change any file, bump `VERSION` in `sw.js` so phones pick up the update.
